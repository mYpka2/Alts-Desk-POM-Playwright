### 1. Alts-Desk POM Playwright (Foundational Project)
My initial foray into structured test automation. This repository served as my first deep dive into the **Page Object Model (POM)** architecture using Playwright.
- **Page Object Model (POM):** Designed a highly maintainable and scalable architecture by cleanly separating page elements and actions (`POM/pageObjects`) from test execution logic (`POM/tests`).
- **Data-Driven Testing:** Isolated and structured test data (`POM/testData`) to efficiently handle varied test scenarios.
- **API & Auth Integration:** Configured Google Auth Library and token management for secure environment testing.
- **Custom Fixtures:** Utilized Playwright fixtures (`POM/fixtures/baseFixtures.ts`) to optimize test setup, teardown, and state management.
